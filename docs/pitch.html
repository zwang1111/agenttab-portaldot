The problem

AI agents can pay. They can’t manage API keys.

Human-shaped billing breaks agents

  • Subscriptions and dashboards assume a human operator
  • API keys are secrets agents shouldn’t hold long-term
  • Per-call on-chain gas kills micropayments

What machine-to-machine needs

  • Escrow once, pay incrementally
  • Cryptographic vouchers, not passwords
  • Provider batch settlement without trusting the agent after deposit

Solution

AgentTab — escrow + EIP-712 vouchers

Agents escrow tPOT once, sign a voucher per API call; providers batch-settle on Portaldot V3 — micropayments without API keys or per-call gas.

open

Payer deposits native tPOT (or ERC-20) for a provider, with expiry. One tab, one escrow.

voucher

Each call: agent signs EIP-712 (tabId, cumulative). Provider returns HTTP 402 if missing/invalid.

settle

Provider submits cumulative + sig once for N calls. Contract pays cumulative − claimed.

refund

After expiry, payer reclaims unspent balance. Reentrancy guard + existence checks on every path.
