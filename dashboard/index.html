Local gateway /quote (HTTP 402)

The provider process in gateway/ sells one call at a time. An unpaid GET /quote is 402 with an AgentTab price and EIP-712 domain. A paid call repeats that request with X-AgentTab-Voucher. This page never signs and never asks for a key.

  1. In the repo: npm run gateway. The default CHAIN_MODE=memory does not send a transaction. The 402 body still names chain 420420777 and the deployed contract.
  2. Unpaid call: curl -i http://127.0.0.1:8402/quote. Expect status 402, header X-AgentTab-Required, and "error": "payment_required", "rail": "agenttab".
  3. Read claimed for the tab (this page, or the SDK). The next voucher cumulative is claimed + price.amountWei from that 402 body. If PRICE_WEI and PRICE_TPOT are unset, the gateway's code default is 10^14 wei (0.0001 tPOT). That default is not a chain balance.
  4. Paid call, key only in the environment: API_BASE=http://127.0.0.1:8402 TAB_ID=1 AGENT_PK=0x… npm run call. The client sends X-AgentTab-Voucher as JSON (tabId, cumulative, signature) or the same JSON in base64url.
  5. The gateway accepts the voucher once, then returns 402 stale on a replay. It calls settle every SETTLE_EVERY accepted calls (default 5) when a provider key is configured.

The probe only calls localhost. From GitHub Pages that is your own machine, and only if the gateway is running there.
